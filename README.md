Landing Page - Portfólio Minimalista
Este projeto foi desenvolvido com o objetivo de criar uma landing page moderna e inclusiva, priorizando dois pilares fundamentais: acessibilidade e responsividade.

✨ Acessibilidade
Estrutura semântica em HTML para melhor interpretação por leitores de tela.

Contraste adequado entre cores para garantir legibilidade.

Navegação por teclado facilitada, permitindo que todos os usuários interajam com os elementos da página.

Uso de atributos ARIA para enriquecer a experiência de quem utiliza tecnologias assistivas.

📱 Responsividade
Layout adaptável para diferentes tamanhos de tela (desktop, tablet e mobile).

Design minimalista que mantém a clareza e a usabilidade em qualquer dispositivo.

Componentes flexíveis e fluidos, garantindo que o conteúdo seja exibido de forma consistente.

Este projeto reflete a importância de unir design funcional e experiência inclusiva, criando uma página que não apenas apresenta o portfólio, mas também respeita e valoriza a diversidade dos usuários.
